sceptre is a from-scratch Rust reimplementation of [EasyOCR](https://github.com/JaidedAI/EasyOCR)'s
pipeline — **CRAFT** text detection then **gen2 CRNN** recognition with CTC decoding, over ONNX. It
agrees with EasyOCR's output on every script it supports, runs **faster** with **no Python
runtime**, and ships as one self-contained binary. Use it as a **library**, a **CLI**, or an
**MCP server**.

## Why sceptre

<CardGrid>
  <Card title="Parity accuracy" icon="approve-check">
    Validated against real EasyOCR output across all eight gen2 scripts — English, Latin, Chinese,
    Japanese, Korean, Cyrillic, Telugu, Kannada — on both text and boxes, to a per-image word-F1
    and box-IoU floor rather than character-for-character equality.
  </Card>
  <Card title="Faster, warm or cold" icon="rocket">
    Higher throughput than EasyOCR's warm reader on the same corpus — and a cold, one-shot CLI run
    still beats it. See [Benchmarks](/reference/benchmarks/) for the measured numbers.
  </Card>
  <Card title="Memory tracks the model, not a runtime" icon="laptop">
    Peak memory is dominated by the CRAFT detector both engines share, so it scales with page
    size rather than with the process behind it — no interpreter or torch runtime to add on top.
    See [Benchmarks](/reference/benchmarks/).
  </Card>
  <Card title="One binary, no Python" icon="seti:rust">
    A single static executable. Models download once, cache locally, and run offline thereafter.
    `cargo install` and go — nothing to `pip install`.
  </Card>
  <Card title="Three surfaces" icon="puzzle">
    The same engine as a Rust library, a CLI (`sceptre`), and an MCP server for agents — drop it into
    a service, a shell pipeline, or an AI tool.
  </Card>
  <Card title="Native or pure-Rust" icon="setting">
    ONNX Runtime (`ort`) for native speed, or a pure-Rust backend (`tract`) for WASM / Android —
    behind one backend seam.
  </Card>
</CardGrid>

## Install

<Tabs syncKey="surface">
  <TabItem label="CLI">
    ```sh
    cargo install sceptre-cli
    sceptre run receipt.png --lang english --format json
    ```
  </TabItem>
  <TabItem label="Library">
    ```toml
    # Cargo.toml — the library ships no default features; enable a backend + model download.
    sceptre = { version = "0.5", features = ["ort-bundled", "download"] }
    ```
  </TabItem>
  <TabItem label="MCP server">
    ```sh
    sceptre mcp --lang english
    ```
  </TabItem>
</Tabs>

Models — CRAFT plus the gen2 recognizers — are fetched from Hugging Face on first use, cached under the
standard HF cache, and sha256-verified. Every run after that is offline.
